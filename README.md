# Multi-currency Accounts and FX Conversion

Hold balances in several currencies, convert at rates that change over time, and handle rounding correctly.

## Project board

Work is tracked on our Jira board: [FX Accounts board](https://bsd-project.atlassian.net/)

## Contributing

- `main` is protected: changes land only through a merged pull request. PRs don't require approvals.
- Branch names must start with `feature/` or `fix/`, for example `feature/rate-versioning` or `fix/rounding-half-even`.
